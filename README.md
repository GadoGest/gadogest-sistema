# Sistema GadoGest

Plataforma de gestão de gado de corte para pequenos produtores rurais, **offline-first**:
app mobile para o campo (Android primeiro) + painel web para o gestor.

> Estado em 16/11/2026: documentação e decisões registradas; **nenhum código implementado ainda**.
